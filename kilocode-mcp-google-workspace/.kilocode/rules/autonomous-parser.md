## Автономный парсинг объявлений аренды квартир

### Команды для запуска парсеров

Пользователь может сказать:
- "Запусти парсер airbnb" → выполнить `python main.py --site airbnb.ru`
- "Запусти парсер halooglasi" → выполнить `python main.py --site halooglasi.com`
- "Запусти парсер oglasi" → выполнить `python main.py --site oglasi.rs`
- "Запусти парсер imovina" → выполнить `python main.py --site imovina.net`
- "Запусти все парсеры" → выполнить `python main.py --all`
- "Спарси по ссылкам ..." → выполнить `python main.py --urls <ссылки>`

### Порядок работы после парсинга

1. Запустить выбранный парсер через `python main.py ...`
2. Если результат успешный:
   - Данные автоматически записываются в Google Sheets через `google_sheets_sync.sync_records()`
   - Deduplication by URL/ID: уже существующие объявления обновляются, новые добавляются
   - Статусы обновляются: Активно / Цена_изменилась / Исчезло / Сдано
   - Даты заполняются: Дата_первого_появления, Дата_нашли, Дата_последнего_обновления
3. Если пользователь хочет посмотреть результат без записи:
   - Добавить флаг `--dry-run`
   - Сохранить в JSON через `--output-json <путь>`

### Автоматическое заполнение таблицы

Kilo сам:
1. Парсит все сайты
2. Извлекает данные из объявлений (включая описание)
3. Переводит на русский язык
4. Заполняет все колонки из VISION.md
5. Записывает в Google Таблицу

### Расписание

Для периодического запуска используй `schedule_wakeup`:
- Интервал: каждые 8 часов
- Команда: `python main.py --all --output-json logs/scan_<date>.json`
- Если парсер упал 3 раза подряд — уведоми пользователя

### Обработка ошибок

Если парсер упал:
1. Запусти повторно через 5 минут
2. Если упал 3 раза подряд — уведоми пользователя
3. Логи сохраняй в `logs/parser_errors.log`

### Структура ответа после парсинга

После успешного парсинга сообщи:
- Сколько всего объявлений найдено
- Сколько прошло фильтр
- Сколько добавлено новых
- Сколько обновлено существующих
- Сколько помечено как "Исчезло"
- Ошибки если были
